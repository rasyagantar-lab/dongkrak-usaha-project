CHANGE REPORT

Files Modified:
- `extension/background.js` (copied to `public/extension/background.js`)

Modifications by Function:
1. `recoverAppBridgeTabs()` & `broadcastStateToAppTabs()`:
   - Removed `matchAboutBlank: true` from the `chrome.scripting.executeScript` target parameter. This resolves the `Unexpected property: 'matchAboutBlank'` TypeError.

2. `inspectAndSyncState()`:
   - Fixed Abandoned Async Message Channels: In every transaction guard (e.g., `if (inspectionId < latestCommittedInspectionId)`), added `safeSendResponse({ status: 'DISCARDED', reason: 'stale_...' })` before returning. This guarantees the request lifecycle completes and prevents the "A listener indicated an asynchronous response by returning true, but the message channel closed before a response was received" error.
   - Fixed Duplicate Content Script Injection: Completely removed the block starting with `if (chrome.scripting && bestTab && bestTab.id) { chrome.scripting.executeScript... }` that was acting as a fallback for failed `chrome.tabs.sendMessage` calls to DongkrakUsaha tabs. This fallback blindly injected `content.js` a second time, colliding with the declarative `manifest.json` injection and throwing the `Identifier 'currentBridgeInstanceId' has already been declared` exception. The recovery block was replaced with a standard `setTimeout(..., 300)` that retries `chrome.tabs.sendMessage` without attempting reinjection.

3. `commitAndBroadcastState()`:
   - Added `safeSendResponse` logic to the stale inspection guard to resolve the promise if a commit is aborted late in the transaction lifecycle.
